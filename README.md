# QQ空间外挂（astrbot_plugin_qzone_ext）

在 AstrBot 里独立接管「定时发说说 + 自动回评」，运行时不会修改原 QQ 空间插件的文件。
协议层移植/改写自 Zhalslar 的 `astrbot_plugin_qzone`，许可与署名见文末「来源与许可」。
人格、模型、配图都走配置，插件本身不带任何角色设定。

## 功能

| 功能 | 说明 |
|---|---|
| 定时发说说 | 每小时随机挑时间点，按跳过概率决定发不发；有每日上限和发布时段 |
| 自动回评 | 定时读取自己说说的新评论并回复，有人格就按人格语气 |
| 主动互动 | 可选：评论好友说说、顺手点赞 |
| 配图 | 可选：预存图库按季节/时段匹配，或调「画图」插件生成 |
| 试运行 | dry-run 只生成不发布，页面可直接看文案和配图预览 |

## 依赖

- AstrBot 4.x（`Star` 插件体系）
- 配图功能需要同仓库的「画图」插件（`astrbot_plugin_draw`）；没装时自动只发纯文字
- 天气走 Open-Meteo，免密钥；取不到就跳过，不编造

## 安装

把目录放进 `AstrBot/data/plugins/astrbot_plugin_qzone_ext`，重启 AstrBot，
在 WebUI 插件页里打开「QQ空间外挂」的页面。

首次使用建议保持 `dry_run` 开着，点「试发一条」看几条文案，满意后再关。

## 配置

所有设置都在插件页面里，也可以直接在插件配置里改。重点几项：

- **人格**：填 AstrBot 人格名；留空用默认人格。人格决定"谁在说话"。
- **说说提示词**：留空用内置（第一人称、40～80 字、随手发一条的口吻）。
- **画面要求**：构图与禁止项，永远生效；留空用内置（只画静物、不要人物文字、正方形）。
- **画风**：优先取「角色卡」里这张卡的配图画风；卡里没写才用「画图」插件的画风。
- **画面描述提示词**：动态配图用；留空用内置（只写景物光线，不画人、不写文字、不编天气）。
- **按这条内容动态写画面描述**：开启后多一次文本模型调用，先写画面再画图；关闭则只把固定要求 + 正文交给画图插件。
- **预存图**：目录里放图片，文件名带季节/时段/天气关键词会被优先匹配；最近用过的 5 张会避开。

## 与角色卡配合

装了 `astrbot_plugin_persona_card` 时，说说外挂会读当前人格对应角色卡的「说说」板块：

- 说说写作要求（口癖、素材、字数）
- 配图画风
- 画面要求 / 负面词（可选覆盖，留空用说说外挂的默认）

没装角色卡就全部用说说外挂自己的默认，两边都能独立工作。

## 配图怎么走

```
说说正文 ─┬─ 动态模式：正文 + 时间天气 → 画面描述 ─┐
          └─ 关闭动态：只把正文附在固定要求后面 ───┴→ 拼上固定要求 → 画图插件
```

- 先按概率决定用预存图还是生成；预存图目录为空或没命中就回落生成。
- 生成失败、画图插件没装 → 自动只发文字，不影响发布。
- 图片上传失败 → 自动改发纯文字，并在页面上标注。

## 页面

插件页面分「概览」和「设置」两块：

- 概览：当前状态、dry-run 开关、试发一条、检查评论、最近生成记录（含配图来源和画面描述）
- 设置：发布节奏、配图、时间天气、素材来源、主动互动、各类提示词

## 说明

- 回评/互动依赖 NapCat 提供的 QQ 空间 cookie，登录态失效时会在日志里提示。
- 所有提示词都可以在页面里改，插件不带任何角色设定或地图名，开箱是通用的。
